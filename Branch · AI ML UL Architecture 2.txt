## Important correction to `_check_retention`

Current logic:

```python id="ia0ejl"
if ret.allow_provider_retention or ret.allow_telemetry:
    return False
```

is directionally correct but should become stricter.

The rule should be:

```python id="rayf3y"
def _check_retention(inp):
    if inp.destination in (None, "local"):
        return True

    ret = inp.retention_policy

    if inp.requested_retention is None:
        return False

    if not ret.allow_provider_retention:
        return False

    if inp.retention_permission != "declared":
        return False

    return True
```

Reason:

A global retention permission should never silently enable an individual operation.
